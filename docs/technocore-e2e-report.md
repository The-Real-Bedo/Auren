## 7. Security Boundaries & Zero-Custody Guarantee

1. **Zero Fund Custody:** The agent never held a private key to the vault, splitter, or paymaster.
2. **Deterministic Policy Gate:** Sponsorship was approved solely because the target contract (`0xFE6389...`), action (`purchaseItem()`), and cost (`0.005 USDC`) strictly satisfied the active policy rule.
3. **Immutable Revenue Routing:** Revenue splitting is enforced by contract immutability on Arc.

## 8. Limitations & Scope

- **Public Testnet RPC Limits:** Arc Testnet public RPC endpoints implement rate limits; client requests incorporate 15-second TTL caching and retry logic with backoff.
- **ERC-4337 Bundler Integration:** In production, UserOperations are batched via dedicated bundlers; this test executed and verified the direct contract execution path and Paymaster signature verification.
